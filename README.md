# Классификация уровня лесных пожаров в Бразилии

## Описание проекта

Проект посвящён анализу данных о лесных пожарах в Бразилии и построению моделей машинного обучения для бинарной классификации наблюдений по количеству пожаров.

**Цель:** определить, превышает ли количество пожаров медианное значение, используя год, штат и месяц наблюдения.

## Данные

- **Количество записей:** 6 454
- **Источник:** [Forest Fires in Brazil — Kaggle](https://www.kaggle.com/datasets/gustavomodelli/forest-fires-in-brazil)
- **Основные признаки:**
  - `year` — год наблюдения;
  - `state` — штат;
  - `month` — месяц;
  - `number` — количество пожаров;
  - `date` — дата наблюдения.

## Этапы работы

1. Загрузка и исследование данных.
2. Проверка пропущенных значений и дубликатов.
3. Создание целевой переменной на основе медианы `number`:
   - `0` — количество пожаров не превышает медиану;
   - `1` — количество пожаров выше медианы.
4. Отбор входных признаков: `year`, `state`, `month`. Признак `number` исключён из входных данных, поскольку на его основе формируется целевая переменная.
5. Кодирование категориальных признаков и стандартизация числовых.
6. Разделение данных на обучающую и тестовую выборки.
7. Обучение и сравнение Logistic Regression и Random Forest.
8. Подбор гиперпараметров Random Forest с помощью GridSearchCV.
9. Оценка моделей и анализ важности признаков.

## Используемые технологии

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Результаты

| Модель | Accuracy | Precision | Recall | F1-score |
|---|---:|---:|---:|---:|
| Logistic Regression | 67.09% | 67.08% | 66.51% | 66.79% |
| Random Forest | 76.06% | 74.95% | 77.92% | 76.41% |
| Random Forest (GridSearchCV) | **77.98%** | **77.04%** | **79.43%** | **78.22%** |

Лучший результат показала модель Random Forest после подбора гиперпараметров. Её Accuracy составила 77.98%, а F1-score — 78.22%.

## Выводы

В ходе проекта были подготовлены данные и построены модели для классификации наблюдений по относительному количеству лесных пожаров. Random Forest показал более высокое качество по сравнению с Logistic Regression.

Результаты показывают, что год, штат и месяц содержат информацию, полезную для классификации количества пожаров относительно медианного значения.

Целевая переменная отражает относительное количество пожаров и не является официальной категорией пожарной опасности. Поэтому модель предназначена для анализа данных и учебных задач, а не для самостоятельного прогнозирования реальных возгораний.
