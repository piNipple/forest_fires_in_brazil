# forest_fires_in_brazil
Классификация уровня лесных пожаров в Бразилии
Цель: предсказать уровень количества пожаров — относительно низкий или высокий — на основе года, штата и месяца наблюдения (бинарная классификация).
Данные: 6454 записи о лесных пожарах в Бразилии. Для анализа выбраны признаки year, state, month, number и date.
Этапы работы:
- Отбор признаков, необходимых для анализа, и проверка данных на пропуски и дубликаты.
- Бинаризация целевой переменной: 0 — количество пожаров не превышает медиану, 1 — количество пожаров выше медианы.
- Исключение number из входных признаков, поскольку на его основе создаётся целевая переменная.
- Кодирование категориальных признаков (state, month) и стандартизация числового признака (year).
- Обучение моделей: Logistic Regression и Random Forest.
- Подбор гиперпараметров Random Forest с помощью GridSearchCV.
- Оценка качества моделей с использованием Accuracy, Precision, Recall и F1-score.
- Анализ важности признаков для определения факторов, наиболее значимых для классификации.
Результаты: лучшей моделью стал Random Forest с подобранными гиперпараметрами. На тестовой выборке Accuracy составила 78%, Precision — 77%, Recall — 79%, F1-score — 78%. Для сравнения, исходная модель Random Forest показала Accuracy около 76%, а Logistic Regression — около 67%.
Выводы: модель Random Forest показала лучшие результаты среди рассмотренных алгоритмов и может использоваться для предварительной классификации наблюдений по относительному количеству лесных пожаров. Год, штат и месяц используются для выявления закономерностей в данных. При этом целевой показатель отражает количество зарегистрированных пожаров относительно медианы, а не официальный уровень пожарной опасности. Поэтому модель не следует рассматривать как самостоятельный инструмент прогнозирования реальных лесных возгораний. Кроме того, качество модели на тестовой выборке не гарантирует аналогичных результатов при применении к новым регионам или будущим периодам.
